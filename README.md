# My Travel App

Interactive travel map & trip planner — visited/wish-list countries, SA-passport visa guide, airports & flight routes, towns, crowd heat map, climate, time zones, Route Explorer and a full Trip Builder with day-by-day program and travel checks.

**Live site:** https://ianventer.github.io/travel-map/

Your data is stored in your own browser (localStorage). Use **Export Data / Import Data** to move it between devices.
